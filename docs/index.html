What it does

It takes a food product from a written brief to a validated formulation, and needs fewer physical trials to get there, because it measures what came back instead of guessing again.

1 · Understand

The brief, parsed

Spec text becomes numeric targets with tolerances, plus category, diet, allergens and claims. What the text cannot answer becomes an open question.

2 · Design

A formulation

Category slots are filled by intent and reconciled to 100 %, with acidulants dosed against the pH target.

3 · Predict

With intervals

Every characteristic carries a 95 % interval and the method that produced it, published before any batch exists.

4 · Trial

On a simulated plant

Known commissioning faults and analytical noise, so a prediction can genuinely be wrong.

5 · Diagnose

Residuals, in sigma

Signature rules rank the probable causes - a thermal offset, a drying shortfall, acid loss - each with its evidence.

6 · Plan

The next version

The measured process offset is corrected first, then the recipe is re-optimised, with a pass probability and a design of experiments.

Evidence

The agent's closed loop against one-factor-at-a-time, on the same cases, the same trial budget and the same pass gate (every hard target on target, measured objective at or above 0.85):

Reduced-sugar mango fruit spread3not reached0.927 vs 0.800

Mean saving: 4.25 trials per case, with 4 of 4 cases reaching the gate against 0 of 4 for the comparison arm. Reproduce it with python run.py --benchmark; every number is read back from the record, never typed in.

Offline learning

A ridge regression for the measured objective and a calibrated logistic regression for pass and fail, both written in plain Python and trained on a versioned dataset the project builds itself. On the held-out test fold they beat their baselines on RMSE, ROC-AUC and Brier score. No API key is used anywhere, and the whole pipeline is reproducible offline with python run.py --build-dataset and python run.py --train.

Run it

python run.py                 # the interface at http://127.0.0.1:8770
python run.py --seed          # the demonstration cases
python run.py --benchmark     # agent vs one-factor-at-a-time
python run.py --report        # the internship report (DOCX, HTML, Markdown)
python run.py --slides        # the presentation (PPTX), rebuilt from the record
python -m unittest discover -s tests -t .   # the suite
